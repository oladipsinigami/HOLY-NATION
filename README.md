# HOLY NATION // PMT 210 & GNS 202 Academic Portal

Welcome to **HOLY NATION**, the official interactive Computer-Based Testing (CBT) portal and study resource hub dedicated exclusively to **PMT 210 / GNS 202: Fundamentals of Economics & Management**.

## 🌟 Key Features

- **Dedicated PMT Focus**: Tailored 100% for PMT 210 and GNS 202 economics and management modules.
- **Dynamic Question Types**:
  - **Multiple Choice Questions (MCQs)**: Microeconomics, Macroeconomics, Factors of Production, Demand & Supply, Inflation, Utility Theory.
  - **German Fill-in-the-Blanks**: Exact string match and intelligent substring validation.
  - **Essay & Theory Questions**: Automated NLP concept keyword evaluation.
- **Study Notes & Courseware Hub**:
  - Editable & downloadable study notes with live Markdown preview.
  - One-click downloads for official Photochem lecture notes and past question PDFs.
- **Dark / Light Glassmorphism UI**: High-contrast, responsive user interface built with Syne & Plus Jakarta Sans typography.
- **Local Storage Persistence**: Save customized notes and exam session history locally in the browser.
